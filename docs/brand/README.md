# arJev brand assets

Generated by `scripts/brand.py` — edit the script, never these files:

```bash
uv run --with cairosvg python scripts/brand.py
```

- `banner-{light,dark}.svg` — the README header (served through `<picture>`).
- `icon-{light,dark}.svg` — the app mark; PNGs at 1024 (Slack app icon), 512, 256, 64, 32.

The mark is an isometric tray with one paper lifted out of it: an arXiv-red
bookmark marks it *selected*, and Jev's magenta star is the pick. It borrows the
visual language of arXiv (warm gray, the red stroke) and TypeSafe, the makers of
Jev (thick isometric line geometry, magenta). It is original artwork and uses
neither organization's logo.
